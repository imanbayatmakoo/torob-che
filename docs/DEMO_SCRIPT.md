# torob-che demo script (~5 minutes)

Live app: https://torob-che.liara.run · Video channel: https://t.me/SCAgenticAIHackathonTransfromers

Setup: Chrome with a mobile device view (iPhone 12/13 Pro), light mode, «از اول» pressed. Don't use the "walking route from my location" button, because it would show the Mac's location.

| Time | On screen | Narration (Persian) |
|---|---|---|
| 0:00–0:30 | Landing page | «سلام، ما تیم Transformers هستیم. تربچه دستیار خرید حضوری روی داده‌های ترب است. هدف ما این است که تصمیم‌گیری برای پیچیده‌ترین کالا، یعنی گوشی، برای یک مصرف‌کنندهٔ معمولی ساده شود؛ از انتخاب مدل تا پیدا کردن مغازه، تماس و مسیر.» |
| 0:30–1:10 | Stay on the landing page (the expert-mode line) | «ما پنج دستهٔ تخصصی داریم: **گوشی موبایل، هدفون و هندزفری، اسپیکر، دوربین مدار بسته و پاوربانک**. معیار انتخاب ما پیچیدگی تصمیم بود، به‌علاوهٔ اینکه در دادهٔ ترب مشخصات قابل مقایسه و تعداد کافی مغازهٔ حضوری داشته باشند. گوشی سخت‌ترین خرید است: قیمت بالا، ده‌ها مشخصه، کالای طرح و ریسک رجیستری. در هدفون، حذف نویز واقعی با میکروفون مکالمه فرق دارد و تقلبی زیاد است. در اسپیکر، توان و باتری و قابل حمل بودن مهم است. دوربین مدار بسته پر از اصطلاح فنی است: رزولوشن، دید در شب، ضدآب بودن. در پاوربانک هم ظرفیت واقعی، شارژ سریع و وزن را راحت اشتباه می‌گیرند. لپ‌تاپ و تلویزیون پیچیده‌اند، اما در این داده مغازهٔ حضوری کمی دارند؛ برای همین با بقیهٔ ۳۴۰۰ دسته در حالت جست‌وجوی عمومی‌اند.» |
| 1:10–2:00 | Type: «برای مامانم گوشی تا ۷۰ میلیون، دوربین و باتری خوب، الان A10 داره و شارژش زود تموم میشه» | «گوشی فعلی نقطهٔ شروع است. کارت‌ها می‌گویند نسبت به گوشی فعلی چه چیزی بهتر می‌شود. همهٔ مدل‌ها و قیمت‌ها از دادهٔ واقعی ترب می‌آیند، نه از مدل زبانی؛ و همه‌جا نوشته "موجودی تأیید نشده".» |
| 2:00–2:20 | Turn on «اقساطی», set the area to جمهوری | «اقساط و منطقه فیلتر سخت‌اند. اگر در منطقه چیزی نبود، بدون اجازهٔ کاربر منطقه را عوض نمی‌کند.» |
| 2:20–3:10 | «کدام مغازه‌ها دارند؟» → shop list, open «چرا رتبهٔ ۱؟» | «مغازه‌ها بر اساس قیمت، تازگی قیمت، گارانتی، رجیستری و ساعت کاری رتبه‌بندی شده‌اند و دلیلش شفاف است. هر فروشنده فقط یک بار می‌آید و مغازهٔ بسته یا بالای بودجه وارد برنامه نمی‌شود.» |
| 3:10–4:00 | **Tap a shop card** → calls → plan → map | «با یک لمس مغازه را انتخاب می‌کنم. تماس شبیه‌سازی است و صادقانه برچسب خورده؛ اگر مغازه جواب ندهد، خودش سراغ مغازهٔ بعدی می‌رود. در برنامهٔ نهایی نقشه، مسیریابی با نشان و بلد، و طبقه و پلاک داخل پاساژ را می‌بینیم.» |
| 4:00–4:40 | «از اول» → «هدفون بی‌سیم با حذف نویز تا ۵ میلیون», then «یخچال ساید بای ساید» | «در هدفون، فقط مدل‌های بی‌سیم با حذف نویز ثبت‌شده می‌آیند و کالای طرح و لوازم جانبی حذف شده‌اند. یخچال در حالت عمومی است: کالا و مغازه‌های واقعی را نشان می‌دهیم، ولی امتیاز کیفیت از خودمان نمی‌سازیم.» |
| 4:40–5:00 | Turn on dark mode, then show the GitHub repo | «حالت تیره هم داریم. برنامه روی لیارا اجرا می‌شود و با GitHub Actions خودکار مستقر می‌شود؛ کد عمومی است. ممنون.» |
